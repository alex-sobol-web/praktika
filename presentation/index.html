1 · Введение

Что тестировали и зачем

Продукт. «Планёрка» — веб-приложение для заметок на совещаниях, планёрках и деловых встречах. Создание, редактирование, удаление и поиск заметок; два способа хранения — SQLite и отдельные файлы.

Цель. Проверить, выполнит ли пользователь, впервые открывший приложение, основные операции без обучения и подсказок.

Что измеряли

  • долю успешно выполненных заданий
  • время выполнения типовых операций
  • операции, вызывающие затруднения
  • уверенность в сохранности заметок — ключевое для записей во время совещания

№Задание участнику

Участники

Инструмент

Электронный протокол: таймер на каждое задание, исход «получилось / не смог», комментарий участника, анкета из 4 утверждений по шкале 1–5.

Правила

Задания сформулированы через цель, а не через кнопки; подсказки не давались. Медиана времени — по успешным попыткам.

4 · Рекомендации

Что доработать — по приоритету

01

Сделать создание заметки очевидным

Выделить кнопку «+ Заметка», при открытии показывать подсказку о первой записи. Устраняет единственный зафиксированный провал — пользователь, не создавший заметку, теряет запись совещания целиком.

02

Упростить выборку по датам

Раскрывать фильтры по умолчанию или добавить быстрые варианты «эта неделя», «прошлая неделя». Сокращает второе по длительности задание.

03

Выяснить барьеры регулярного использования

Короткое интервью с участниками до внесения изменений: этот показатель анкеты оказался наименьшим, а причину по данным теста не установить.

5 · Заключение

Итоги и деловые последствия

Основные операции новый пользователь выполняет без обучения; доверие к сохранности данных высокое. Ключевой риск — первый шаг: создание заметки.

Для приложения, которым пользуются во время совещания, главный экономический эффект даёт не экономия секунд, а снижение доли потерянных записей: восстановить содержание совещания по памяти дороже, чем лишние секунды на заметку. Поэтому доработка № 1 — приоритетная.
